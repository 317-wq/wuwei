### 1.2 任务判断

- **材料与 Gold 关系**：材料充分且自洽；Gold 与材料一致，但 Gold 的形式有缺陷——整本 `gold/expected_answer.xlsx` **0 条公式**，`控制!F2:F17` 的“带符号差额”是硬编码 0（其中 `F6=2.22e-16`），“可重算”只是名义上的。Gold 的 `原值追溯!K/L` 列坐标（如 `E4:G4`、`E22:G22`）逐行正确，可作为追溯基线。
- **主要难度来源**：**非业务摩擦**。业务侧只有 6 店 × 3 餐段，5 份 rollout 的桥、餐段、状态、闭合全部算对；真正拉开差距的是抬头/表结构/控制项措辞与冻结哈希。证据：01–05 的 `餐段归因`（或 `时段贡献`）数值完全相同，但 R5 只给了 04/05；02 的“三类组合贡献率=100%”与 05 的“三类有符号贡献=100%”语义等价，R6B 却一个 0 一个 1。
- **最重要的设计问题及最小修复（3 条）**：
  1. **instruction 泄漏一条命令的解法**：`instruction.md` 末尾【交付提示】直接给出 `python3 /workspace/solution/solve.py …`，并要求“先查看环境里的作业规程”。若 solve.py 存在，任务退化为“找到脚本”，测不到归因能力；若不存在，则误导 Agent 并浪费步数。更糟的是它与评分器的 `evaluator_instruction_adoption` 一票否决（`program_judge.py:169`）语义冲突。**最小修复**：删除该段与 solve.py（若存在），或改为不可执行的环境说明；同时在 rubric 中明确“引用任务文本”不触发一票否决。
  2. **Gold 与 R9 互相矛盾**：任务要求交付“可重算”工作簿，R9 却按“公式+关键词共现”给 6%；Gold 没有任何公式，实测 `r9_dependency(gold)=0`，即 Gold 走未见路径、其余项按满分计也只能得 **0.940069**，与冻结的 1.0 矛盾。**最小修复**：用公式重生成 Gold（至少 `控制` 页差额、桥贡献、餐段贡献为公式）；或明确“静态值等价”，把 R9 权重归零并删除该维度。
  3. **instruction 未点名两个比较期间**：全文只说“相邻期间/两期”，实际是 2023→2024 与 2024→2025。probe-02 正是只做了一个期间的样本；把“期间一”理解成 2024 vs 2023 是可辩护的误读。**最小修复**：在 instruction 中写明“需比较 2023→2024 与 2024→2025 两组”。

### 4.2 假阳性与假阴性案例

**假阳性（当前规则会给高分，且同一错误因写法不同而大幅摆动）**：以“毛变动份额”代替“品牌净变化分母”的完整工作簿。期间一毛变动 = 23+89+64 = 176，三格写成 13.07%/50.57%/36.36%（绝对份额，合计 100%），符号也不对（关闭写成正）。它满足 R6B（合计=100%，→30%）；餐段链正确故 R6E=1（→35%）；带公式故 R9=1（→6%）；R4 因三条链的贡献叶失败只拿一半（0.8×0.5×23.4493%=9.38%）；合计 ≈ **0.8593**。同一实质错误若把关闭改写成 −36.36%（符号正确、但不合分母，三格合计 27.3%），R6B 立刻归零，总分跌到 ≈ **0.5593** —— **同一个错误因“正负号写法”相差 30 个百分点**。**根因**：R6B/R6E 只验“合计=100%”，不验分母与符号，而它们合计占 65%。

### 4.5 程序化与人工/语义复核

- **可程序化**：R1（可读/可编辑/三层共现）、R2（76 值绑定与比对）、R3（12 状态）、R4/R5（从叶子重算）、R6（闭合重算）、R8（坐标解析回读）、V1、V3、D1、D4。这些都应给出“叶子级”证据（`{期间,对象,指标,观察值,期望值,通过}`），而不是整份给一个分。
- **只能人工/语义**：R7 的“是否先结论后依据”“是否明确正式采用”；D2/D3/D5 的意图判断；合理但少见的版式是否等价；以及所有 `unmeasurable` 的裁定。
- **人工不得产生第二套数值分**：人工只能在公开条目内做三件事——确认、否决、标记 `unmeasurable`；每次判定必须写明条目 ID 与单元格坐标；两名评审不一致时默认 `unmeasurable`（不计分也不扣分），而不是折中给分；人工不得新增维度、不得改权重、不得凭“看起来专业”加分。

### 4.6 结构差异、解析失败、普通遗漏与同根因

- **结构差异**：按 `(期间, 对象, 指标)` 归一化后比值，不看表名、列序、宽长表；接受 `2023→2024`/`2023年→2024年`/`2023-2024`，接受 `0.4792`/`47.92%`/`47.9%`（显示精度内），接受“千人次”或一致换算后的“人次”，接受合计独立成表，接受公式或静态值。
- **解析失败**：三态区分 `wrong / unmeasurable / unreadable`。整份不可读 → V1=0 并给原因；部分不可解析 → 已解析叶子照常计分，未解析叶子记 `unmeasurable` 并从分母剔除，该维度封顶 90%，不触发任何扣分；`unmeasurable` 超过 40% → 转人工按同一批叶子复核，仍不得引入新分数。
- **普通遗漏**：只在该叶子所属条目内按比例失去（如 R2 缺 1/76 只扣 0.13 个百分点），不追加扣分、不向其他条目传导；缺一整个期间则按该期间的叶子比例失去（约 50%），并记录“部分完成”，不触发 V1/V3。
- **同一根因**：先建根因表（如“分母用了 23”），把它在各 sheet 的每次出现映射到叶子；每个根因只在最重的一个叶子上计一次扣分，其余同根因叶子标 `duplicate` 不再扣；`duplicate` 不得触发 D2/D3。
